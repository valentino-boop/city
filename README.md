# 서울 유동인구 · 3D 시티맵

서울 생활인구(행정동, 2025.08–2026.07 평균)를 건물 262,694동·도로 79,413개 위에 얹은
웹GL 3D 지도입니다. 시간(00–24시)·평일/주말 슬라이더로 도로 유동인구(번잡도)를 색·굵기·발광으로
보여주고, 해가 지면 야간 팔레트와 창문 불빛·도로 글로우로 전환됩니다.

- `index.html`, `app.js` — 화면과 지도 로직 (MapLibre GL JS 5)
- `data/buildings.bin` — 건물 footprint(int16)·높이·색상 카테고리
- `data/roads.bin` — 도로 폴리라인 + 24시간×평일/주말 혼잡도(4bit 니블)
- `data/lights.bin` — 야간 창문 불빛 포인트
- `data/water.json` — 한강·지천 폴리곤
- `build_data.py` — 원본 OSM 데이터에서 위 바이너리를 만드는 스크립트

## 렌더링 방식 메모

- **도로(유동인구)**: MapLibre `line` 레이어의 데이터 기반 paint(`match` 표현식)로 시간대를
  바꾸면 25만 개 세그먼트가 매번 재버킷팅되어 한 프레임에 수백 ms씩 끊깁니다. 그래서 도로는
  커스텀 WebGL 레이어(`cityroads`)로 그리고, 정점마다 24시간 니블을 실어 보내 **셰이더가
  시간 유니폼으로 색·굵기를 계산**합니다. 시간이 흐를 때 갱신되는 것은 1바이트/정점짜리
  레벨 버퍼와 유니폼뿐이라 재생 중 스타일 재계산이 없습니다(0회).
- **야간 조명**: `light`(색·세기·방향)로 건물을 달빛 톤으로 들어올리고, `lights.bin` 포인트를
  커스텀 레이어(`citylights`)로 벽면에 얹습니다. 깜빡임은 벽시계가 아니라 **지도 시간**에
  연동되어 일시정지 상태에서는 완전히 정지합니다.
- 커스텀 레이어 행렬은 절대 머케이터 좌표 기준입니다(`world = origin + k·metres`).
- 테마(배경·지형·물·광원) 갱신은 1/24 단계로 양자화해 재생 중 프레임이 끊기지 않게 합니다.
